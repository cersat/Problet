# Problet

Браузер, написанный с нуля на Electron, с упором на настраиваемый интерфейс и удобную работу с вкладками. Свои панели и кнопки, пространства, заморозка вкладок, блокировщик рекламы, менеджер паролей и встроенные инструменты вместо расширений.

## Скачать

Сборки для Linux, Windows и macOS появляются на странице [Releases](https://github.com/cersat/Problet/releases) при каждом изменении кода.

| Система | Файл | Как запустить |
| --- | --- | --- |
| Linux | `.AppImage` или `.tar.gz` | Сделай AppImage исполняемым (`chmod +x Problet-*.AppImage`) и запусти |
| Windows | установщик `.exe` или `.zip` | Запусти установщик |
| macOS | `.dmg` или `.zip` | Приложение не подписано: при первом запуске открой его через контекстное меню → «Открыть» |

Обновляться можно прямо в браузере: «Настройки» → «Обновления». Проверка идёт при запуске и по расписанию (период выбирается; пока свежая версия ещё собирается, можно проверять чаще), в настройках виден список изменений последней версии. AppImage заменяет себя сам, установщик на Windows скачивается и запускается, на macOS скачивается `.dmg` и открывается установщик.

## Что умеет

- **Вкладки**: перетаскивание, закрепление, переименование (правая кнопка → «Переименовать вкладку», имя держится до закрытия), восстановление сессии, значки сайтов (с кешем), Ctrl+1…9, список всех вкладок (Ctrl+Shift+A) и возврат закрытой (Ctrl+Shift+T). По желанию вторая вкладка с тем же адресом не открывается, а переводит в первую.
- **Заморозка вкладок**: вкладки, которые давно не открывали, замораживаются через выбранное время (от минуты до суток), по желанию при запуске и при смене пространства. Замороженные можно выгружать из памяти, тогда история вкладки сохраняется на диск, и она открывается там же, где была.
- **Режим инкогнито** (Ctrl+Shift+N, правая кнопка на «+», пункт в меню ссылки): отдельная сессия в памяти. История, пароли, масштаб и поисковые запросы не сохраняются, куки стираются при закрытии последней такой вкладки. Скачивание из инкогнито можно подтверждать.
- **Панели**: три панели (вкладок, инструментов, закладок) и окно страницы можно переставлять в любом порядке, вкладки уходят и в боковую панель. Каждая кнопка (назад, вперёд, обновить, апплеты, «+», пространства, кнопки окна) переселяется на любую панель или скрывается, порядок меняется стрелками. Три переменных промежутка сдвигают элементы к краям панели; на панели без промежутка вкладки и закладки растягиваются, а адресная строка с промежутком сжимается до текста. Панель вкладок растягивается мышью до двойного размера, на высокой панели вкладки ложатся в два слоя (или названия переносятся на несколько строк). Стрелки «назад» и «вперёд» выбираются в теме.
- **Свои кнопки**: кнопка с названием и значком, которая открывает адрес, выполняет скрипт на открытой странице или запускает любую команду браузера из списка горячих клавиш. Ставится на любую панель.
- **Адресная строка**: подсказки из закладок, истории и поиска, встроенный калькулятор.
- **Пространства**: у каждой вкладки есть пространство, в каждом показаны только его вкладки (или все сразу, если не разделять). Апплет пространств выбирает текущее, создаёт, переименовывает и удаляет их; открывается вкладкой или всплывающей панелью.
- **Таблица символов**: апплет на панели инструментов, символ вставляется в поле, где стоял курсор (на странице или в адресной строке).
- **Закладки и история**: папки, правая кнопка на закладке (изменить, удалить, своя иконка: рисуется в SVG-редакторе и показывается вместо значка сайта), импорт и экспорт (JSON и HTML как у Chrome и Firefox), поиск по истории. Закладки можно перенести прямо из Chrome, Edge, Brave, Vivaldi, Opera и Firefox, которые стоят на компьютере (Настройки, Данные).
- **Загрузки**: свой список, отмена, показ в папке.
- **Локальные файлы**: папка, открытая как адрес, показывается проводником (`problet://files`), `.svg` открывается графическим редактором (`problet://svgedit`). Редактор в духе «Костюмов» Скретча: фигуры, кисть, текст, слои, отмена; сохраняет в файл, выгружает в PNG (×1…×8) и в режиме иконки закладки сохраняет рисунок в закладку. Это редактор из [scratch-paint](https://github.com/TurboWarp/scratch-paint) (TurboWarp, GPL-3.0), его лицензия лежит в `pages/svgedit.LICENSE.txt`, сборка описана в `tools/paint/build.sh`.
- **Масштаб**: запоминается для каждого сайта.
- **Скриншот** всей страницы (Ctrl+Shift+S), **код страницы** (Ctrl+U), **инструменты разработчика** (F12).
- **Поиск по странице** (Ctrl+F) со счётчиком.
- **Печать** (Ctrl+P) и **сохранение в PDF** (Ctrl+Alt+P).
- **Расширения Chrome**: распакованные папки с manifest.json добавляются в настройках. Поддерживаются не все API, сложные расширения могут работать не полностью.
- **Горячие клавиши**: каждое сочетание переназначается в настройках.
- **Блокировщик рекламы и трекеров**: списки доменов и путей, реклама заменяется заглушкой «Реклама заблокирована», можно добавить свой список блокировки. Сам блокировщик по умолчанию выключен.
- **Предупреждение о небезопасных сайтах**: переход на `http://` по желанию сначала показывает страницу-предупреждение.
- **Приватность**: заголовок Do Not Track, маскировка под Chrome, Problet или Firefox (User-Agent, Sec-CH-UA и `navigator`). Версия Chrome берётся у настоящего движка.
- **Менеджер паролей**: зашифрованное хранилище (AES-256-GCM, ключ из мастер-пароля через scrypt), сохранение и подстановка через всплывающее окно (при запертом хранилище оно просит мастер-пароль), вход в два шага (сначала логин, потом пароль) тоже подставляется, экспорт и импорт в CSV с проверкой мастер-пароля.
- **Темы**: тёмная и светлая, пастельные акценты, выбор стрелок «назад» и «вперёд».
- **Браузер по умолчанию**: кнопка в «Данные» (на Linux для AppImage создаёт ярлык и назначает его).
- **Служебные страницы**: `problet://settings`, `bookmarks`, `history`, `downloads`, `passwords`, `version`, `spaces`, `files`, `svgedit`. Несуществующая служебная страница показывает аккуратную ошибку 404. Если семь раз нажать на версию в карточке на `problet://version`, откроется меню отладки (`problet://version/debug/`): принудительное обновление, очистка куки, сброс настроек, удаление расширений.

## Что стоит знать

- Маскировка меняет заголовки и то, что видит JavaScript в основном окне страницы. В iframe чужих сайтов она не действует, а сам движок остаётся Chromium.
- Мастер-пароль нигде не хранится. Забудешь его, и пароли не восстановить.
- CSV с паролями не зашифрован: после переноса удали файл.
- Ключи доступа (passkeys, WebAuthn) отключены: сайты, которые их предлагают, продолжают вход обычным паролем. Если сайт обязательно требует ключ, войти в Problet не получится.
- Подстановка паролей работает только в основном окне страницы и только на том же адресе (схема, хост и порт), где пароль был сохранён.

## Сборка из исходников

Нужен Node.js.

```
npm install
npm start
```

Установочные файлы:

```
npm run dist
```

Сборки для всех систем делает GitHub Actions: каждое изменение в `main` обновляет релиз `latest`, а метка `v*` создаёт релиз с этой версией.

## Данные

Настройки, закладки, история и сессия лежат в `data.json`, пароли в `vault.json` (в папке данных приложения, её путь показан на странице `problet://version`).

## Режим без окна

`problet --headless` запускает браузер скрыто, без дисплея, с одноразовым профилем (он удаляется при выходе; свой профиль задаётся через `--user-data-dir=`). Можно запускать сколько угодно копий.

Одноразовая загрузка с отчётом JSON в stdout:

```
problet --headless --fetch=https://example.com --runs=3 --wait=4000 --adblock --text --shot=page.png --eval="document.title"
```

В отчёте — заголовок, итоговый адрес, время загрузки и сводка запросов по хостам: сколько запросов и сколько из них заблокировано (`hosts`). `--runs` повторяет загрузку с чистого листа, `--size=1280x800` задаёт размер страницы.

Управление по HTTP: `problet --headless [--control-port=N]` печатает в stdout строку `PROBLET_HEADLESS {url, port, token, pid}` и пишет то же в `/tmp/problet/headless.json`. Токен передаётся в заголовке `x-token`.

| Запрос | Что делает |
| --- | --- |
| `GET /tabs` | список вкладок |
| `POST /open {url, wait}` | открыть адрес в новой вкладке и дождаться загрузки |
| `POST /eval {tab, js}` | выполнить JS на странице |
| `GET /text?tab=` | текст страницы |
| `GET /screenshot?tab=` | снимок PNG |
| `GET /requests?clear=1` | сводка запросов по хостам |
| `GET /console?clear=1` | ошибки и предупреждения из консоли страниц (в `--fetch` — поле `console`) |
| `GET /log?lines=200` | хвост журнала `/tmp/problet/log` |
| `POST /close {tab}` | закрыть вкладку |
| `POST /quit` | выйти |
