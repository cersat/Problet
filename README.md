# Problet

Небольшой браузер, написанный с нуля на Electron. Минимум лишнего: вкладки, закладки, история, загрузки, блокировщик рекламы, менеджер паролей и аккуратные настройки.

## Скачать

Сборки для Linux, Windows и macOS появляются на странице [Releases](https://github.com/cersat/Problet/releases) при каждом изменении кода.

| Система | Файл | Как запустить |
| --- | --- | --- |
| Linux | `.AppImage` или `.tar.gz` | Сделай AppImage исполняемым (`chmod +x Problet-*.AppImage`) и запусти |
| Windows | установщик `.exe` или `.zip` | Запусти установщик |
| macOS | `.dmg` или `.zip` | Приложение не подписано: при первом запуске открой его через контекстное меню → «Открыть» |

Обновляться можно прямо в браузере: «Настройки» → «Обновления». AppImage заменяет себя сам, установщик на Windows скачивается и запускается, на macOS откроется страница загрузки.

## Что умеет

- **Вкладки**: перетаскивание, закрепление, восстановление сессии, значки сайтов (с кешем), Ctrl+1…9, список всех вкладок (Ctrl+Shift+A) и возврат закрытой (Ctrl+Shift+T).
- **Адресная строка**: подсказки из закладок, истории и поиска, встроенный калькулятор.
- **Закладки и история**: папки, импорт и экспорт (JSON и HTML как у Chrome и Firefox), поиск по истории. Закладки можно перенести прямо из Chrome, Edge, Brave, Vivaldi, Opera и Firefox, которые стоят на компьютере (Настройки, Данные).
- **Загрузки**: свой список, отмена, показ в папке.
- **Масштаб**: запоминается для каждого сайта.
- **Скриншот** всей страницы (Ctrl+Shift+S), **код страницы** (Ctrl+U), **инструменты разработчика** (F12).
- **Поиск по странице** (Ctrl+F) со счётчиком.
- **Печать** (Ctrl+P) и **сохранение в PDF** (Ctrl+Alt+P).
- **Расширения Chrome**: распакованные папки с manifest.json добавляются в настройках. Поддерживаются не все API, сложные расширения могут работать не полностью.
- **Горячие клавиши**: каждое сочетание переназначается в настройках.
- **Блокировщик рекламы и трекеров**: списки доменов и путей, реклама заменяется заглушкой «Реклама заблокирована». Сам блокировщик по умолчанию выключен.
- **Приватность**: заголовок Do Not Track, маскировка под Chrome, Problet или Firefox (User-Agent, Sec-CH-UA и `navigator`). Версия Chrome берётся у настоящего движка.
- **Менеджер паролей**: зашифрованное хранилище (AES-256-GCM, ключ из мастер-пароля через scrypt), сохранение и подстановка по нажатию на поле, экспорт и импорт в CSV с проверкой мастер-пароля.
- **Темы**: тёмная и светлая, пастельные акценты.
- **Служебные страницы**: `problet://settings`, `bookmarks`, `history`, `downloads`, `passwords`, `version`.

## Что стоит знать

- Маскировка меняет заголовки и то, что видит JavaScript в основном окне страницы. В iframe чужих сайтов она не действует, а сам движок остаётся Chromium.
- Мастер-пароль нигде не хранится. Забудешь его, и пароли не восстановить.
- CSV с паролями не зашифрован: после переноса удали файл.
- Подстановка паролей работает только в основном окне страницы и только на том же адресе (схема, хост и порт), где пароль был сохранён.

## Сборка из исходников

Нужен Node.js.

```
npm install
npm start
```

Установочные файлы:

```
npm run dist
```

Сборки для всех систем делает GitHub Actions: каждое изменение в `main` обновляет релиз `latest`, а метка `v*` создаёт релиз с этой версией.

## Данные

Настройки, закладки, история и сессия лежат в `data.json`, пароли в `vault.json` (в папке данных приложения, её путь показан на странице `problet://version`).
