# Правила по пути: хост|часть пути. Блокируется запрос к хосту (или его поддомену), путь которого начинается с этой части; с «~» впереди часть может быть в любом месте пути
# Meta: пиксель и его конфигурация. Сам домен нужен для входа через Facebook и кнопок, поэтому блокируются только эти пути
connect.facebook.net|~/fbevents.js
connect.facebook.net|/signals/
www.facebook.com|/tr/
www.facebook.com|/tr?
