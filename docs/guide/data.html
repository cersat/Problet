Папка данных

Всё личное лежит в одной папке. Точный путь показан на странице problet://version («Папка с данными»), а в меню отладки есть кнопка «Открыть». Обычно это:

СистемаПуть
Linux~/.config/Problet
Windows%APPDATA%\Problet
macOS~/Library/Application Support/Problet

Внутри:

Файл или папкаЧто там
data.jsonНастройки, закладки и папки, история посещений и поиска, сессия (открытые вкладки), масштаб сайтов, список загрузок.
vault.jsonПароли, зашифрованные мастер-паролем.
bookmark-backups/Автоматические копии закладок (если для них не выбрана своя папка).
offline/Страницы, сохранённые для офлайна.
extensions.json, extensions/Список расширений Chrome и расширения, установленные из Chrome Web Store.
addons/, addon-data/Аддоны Problet и их данные.
frozen/История выгруженных из памяти вкладок (очищается при запуске).
Cache/ и другие папки ChromiumКеш, куки, локальные хранилища сайтов.

Журнал работы браузера пишется в /tmp/problet/log на Linux и macOS и в %TEMP%\problet\log на Windows. Он пригодится, если что-то сломалось.

Экспорт браузера

Настройки → Данные → Экспорт браузера сохраняет в один файл .problet (сжатый архив) всё, что Problet хранит в папке данных:

  • настройки, закладки и папки, историю, историю поиска, пространства и открытые вкладки, масштаб и разрешения сайтов, список загрузок;
  • хранилище паролей — оно остаётся зашифрованным мастер-паролем, как на диске;
  • блокнот, расширения Chrome, аддоны Problet и их данные, офлайн-страницы, копии закладок;
  • вход в аккаунт Problet — только если задан «Пароль файла»: ключ шифрования данных аккаунта и токен кладутся в файл зашифрованными этим паролем (scrypt и AES-256-GCM). Для файла создаётся отдельный токен входа, на сервере он виден в списке устройств как «Из файла экспорта», пока не будет использован.

В файл не входят куки и кеш сайтов (ими владеет Chromium) и родительский контроль (он лежит отдельно и привязан к пользователю системы).

Импорт: Настройки → Данные → Импорт браузера или кнопка «Выбрать файл…» в разделе «Восстановить из файла» на экране приветствия. Он заменяет все данные, прежний data.json остаётся рядом как data.json.before-import, после чего Problet перезапускается. Если в файле есть вход в аккаунт, нужен пароль файла; с неверным паролем всё остальное восстанавливается, а в аккаунт нужно войти вручную. Импортированное устройство в списке устройств аккаунта получает своё имя и не заменяет исходное.

Резервная копия

Настройки → Данные → Резервная копия → «Экспорт» сохраняет одним JSON-файлом настройки, закладки, папки и историю поиска. Пароли в копию не входят — их переносят отдельно (см. ниже).

«Импорт» спрашивает, как поступить:

  • Объединить — закладки и история поиска добавляются к текущим, повторяющиеся закладки пропускаются, настройки остаются как есть;
  • Заменить — текущие закладки, папки, история поиска и настройки полностью заменяются данными из файла. История посещений, сессия и загрузки остаются.

Для закладок есть ещё автоматические копии.

Переезд на другой компьютер

  1. На старом компьютере: Настройки → Данные → «Резервная копия» → «Экспорт» и «Пароли» → «Экспорт» (CSV).
  2. Поставь Problet на новом компьютере (установка).
  3. На новом: «Резервная копия» → «Импорт» → «Заменить», затем «Пароли» → «Импорт».
  4. Удали CSV с паролями — он не зашифрован.
  5. Расширения и аддоны поставь заново.

Можно и просто скопировать всю папку данных целиком, пока Problet закрыт. Тогда переедет всё, включая входы на сайты, историю посещений и расширения. Пароли откроются тем же мастер-паролем.

Перенос из другого браузера

ЧтоКак
ЗакладкиДанные → Из другого браузера → «Импортировать» — прямо из установленных Chrome, Edge, Brave, Vivaldi, Opera и Firefox. Или выгрузи закладки в HTML в старом браузере и импортируй в «Закладки в HTML».
ПаролиВыгрузи пароли в CSV в старом браузере (Chrome: «Менеджер паролей» → «Настройки» → «Экспорт паролей»), затем Данные → Пароли → «Импорт».
РасширенияПоставь из Chrome Web Store прямо в Problet.
