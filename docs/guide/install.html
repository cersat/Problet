Установка и обновления

Problet собирается автоматически под Linux, Windows и macOS после каждого изменения кода. Обновляется сам, прямо из настроек.

Где скачать

Все файлы лежат на странице Releases на GitHub:

  • «Последняя сборка» (тег latest) — самое свежее состояние кода. Обновляется после каждого изменения, именно её смотрит встроенное автообновление.
  • Релизы версий (v9.1.0, v8.0.0 и так далее) — сохранённые сборки. Отдельный релиз появляется сам, когда меняется первое или второе число версии, поэтому старую версию всегда можно найти и поставить.

Имена файлов устроены как Problet-<версия>-<система>-<процессор>:

СистемаФайлыЧто выбрать
Linux (x86_64)…-linux-x86_64.AppImage, …-linux-x64.tar.gzAppImage: один файл, обновляется сам. tar.gz — архив для тех, кто хочет распаковать вручную.
Linux (arm64)…-linux-arm64.AppImage, …-linux-arm64.tar.gzДля процессоров ARM: Raspberry Pi 4 и 5 с 64-разрядной системой, ноутбуки и серверы на ARM. Обновляется так же.
Windows…-win-x64.exe, …-win-x64.zipУстановщик .exe. Zip — переносная версия без установки.
macOS…-mac-arm64.dmg, …-mac-x64.dmg (и такие же .zip)arm64 — для Mac на Apple Silicon (M1 и новее), x64 — для Mac на Intel.

Сайт и потоки stable и beta

Главный источник загрузки — сайт problet.dar-site.uk: на нём главная страница, эта документация (/guide) и файлы сборок. Файлы раздаются в двух потоках:

  • stable — серия (первые два числа версии) на одну ниже последней, например при последней 9.6.x это 9.5.x. Она проверена временем, до бета-версий не обновляется. Первой stable считается 9.4: пока последняя версия 9.4.x, stable — это 9.4.0, а когда выйдет 9.5, stable перейдёт на свежие сборки серии 9.4.
  • beta — самая свежая сборка. Бета-сборки получают значок браузера с жёлто-оранжевой надписью «beta».

Файл нужной системы лежит по адресу вида /download/stable/windows-setup, /download/stable/linux-appimage (для ARM — linux-arm64-appimage), /download/beta/mac-dmg; /api/versions показывает, какие версии сейчас лежат в потоках. С одного адреса можно скачивать не больше 120 раз в час.

Поток для самого браузера выбирается в Настройки → Обновления → Поток обновлений. С stable на beta можно перейти в любой момент, с beta на stable браузер обновится, когда появится stable-версия не ниже той, что ты используешь.

Установщики

  • Windows, .exe — при запуске спрашивает язык (русский или English), затем «Обычная установка» или «Портативная». Портативная ставит программу и все её данные в одну выбранную папку: ярлыков, записей в системе и деинсталлятора нет, папку можно перенести или стереть (данные лежат в подпапке data). Рядом с программой при этом создаётся файл portable.txt.
  • Windows, веб-установщик — файл …-win-x64-web.exe в несколько мегабайт: сам скачивает Problet с GitHub и ставит его так же, как обычный установщик.
  • Linux — скрипт Problet-web-linux.sh (stable или beta параметром): скачивает настоящий AppImage для твоей архитектуры (x86_64 или arm64) с индикатором загрузки (окно zenity или kdialog, иначе полоса в терминале), сам становится файлом Problet.AppImage, делает его исполняемым и запускает.
  • macOS — скрипт Problet-web-mac.command: скачивает архив под твой процессор, кладёт Problet.app в «Программы» и открывает.

Первый запуск

На чистом профиле Problet открывает страницу приветствия: язык, тёмная тема, положение вкладок, панель закладок и поисковик. Выбор применяется сразу, кнопка «Начать» открывает новую вкладку. Потом всё это можно поменять в настройках.

Linux

AppImage нужно сделать исполняемым, иначе он не запустится:

chmod +x Problet-*.AppImage
./Problet-*.AppImage

Или в файловом менеджере: свойства файла → права → «Разрешить выполнение как программы».

Windows

Запусти установщик. Windows может показать предупреждение SmartScreen, потому что программа не подписана сертификатом: «Подробнее» → «Выполнить в любом случае».

macOS

Приложение не подписано, поэтому при первом запуске его нужно открыть через контекстное меню: правая кнопка на Problet → «Открыть» → «Открыть». Дальше оно запускается как обычно.

Обновления

Раздел Настройки → Обновления. По умолчанию Problet сам проверяет последнюю сборку каждые 6 часов и при запуске, скачивает новую версию и ставит её после перезапуска. Там же видны текущая версия и список изменений последней сборки («Что нового»).

НастройкаЧто делает
Обновлять автоматическиПроверять и скачивать новую версию по расписанию. Включено по умолчанию.
Период авто-проверки15 минут … 24 часа, по умолчанию 6 часов.
Увеличивать частоту проверки, когда обновление собираетсяЕсли новая версия уже есть в коде, но её сборка ещё идёт, проверка делается каждые 2 минуты.
Перезагружать автоматическиКак только новая версия скачана, Problet сам перезапускается. Вкладки вернутся, только если при запуске выбрано восстановление сессии. Окно откроется на том же месте и в том же виде (обычное, развёрнутое или во весь экран), а если оно было в фоне или свёрнуто, фокус не заберёт.

Как именно ставится обновление, зависит от того, как ты установил Problet:

  • Linux, AppImage — новый файл скачивается и подменяет запущенный, после перезапуска работает новая версия.
  • Linux, tar.gz — Problet не может обновить распакованный архив сам и открывает страницу релиза.
  • Windows, установщик — скачивается новый установщик и тихо ставится поверх.
  • Windows, zip — новый zip распаковывается поверх текущей папки.
  • macOS — новый .dmg скачивается в «Загрузки» и открывается. Перетащить приложение в «Программы» нужно самому: неподписанное приложение не может заменить себя.

Кнопка «Проверить» на странице problet://version и в настройках проверяет обновление сразу. На панели может стоять кнопка «Значок обновления» — она появляется, когда новая версия готова.

Команда problet в терминале

При запуске Problet сам создаёт команду для терминала:

  • Linux — скрипт ~/.local/bin/problet;
  • Windows — problet.cmd в отдельной папке, которая добавляется в PATH пользователя (заработает в новых окнах терминала).

Команда запускает браузер, передаёт ему все аргументы без изменений и ждёт, пока браузер закроется (сообщения браузера идут в этот терминал). Если Problet уже открыт, адрес откроется в нём новой вкладкой, а команда сразу завершится.

С ключом --detach браузер запускается в фоне: команда сразу возвращает терминал и ничего в него не пишет.

problet https://example.com
problet --detach https://example.com
problet --headless --fetch=https://example.com

Про ключи режима без окна — на странице Режим без окна.

Браузер по умолчанию

Настройки → Данные → Стандартный браузер → «Сделать стандартным браузером». На Linux для AppImage Problet создаёт ярлык приложения и назначает его через xdg-settings. На Windows и macOS система может попросить подтвердить выбор в своих настройках.

Удаление

  • Linux: удали файл AppImage, команду ~/.local/bin/problet и, если нужно, папку данных.
  • Windows: «Приложения» в параметрах системы → Problet → «Удалить».
  • macOS: перетащи Problet из «Программ» в корзину.

Из самой программы: Настройки → Главная → Удалить Problet. Браузер спросит, удалять ли вместе с программой и данные. Так удаляется установка через установщик Windows, портативная папка, AppImage и приложение macOS; пакеты из менеджера системы удаляются самим менеджером.

Папка данных (настройки, закладки, пароли) при удалении программы остаётся. Где она лежит — на странице Данные.
