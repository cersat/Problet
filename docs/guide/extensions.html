Расширения и аддоны

Problet понимает два вида дополнений: расширения Chrome (в том числе прямо из Chrome Web Store) и собственные аддоны Problet. Оба управляются в Настройки → Расширения.

Чем они отличаются

Расширения ChromeАддоны Problet
ОткудаChrome Web Store или папка с manifest.jsonКаталог ProbletAddons, ссылка на addon.json или архив
СовместимостьРаботают не все API Chrome: недостающие заменены заглушками, сложные расширения могут работать не полностьюСделаны под Problet, работают полностью
Что могутЧто позволяет ChromeБольше: файлы, запуск программ, сеть без ограничений CORS — но спрашивают разрешения
КнопкаУ каждого расширения своя кнопка, открывает его окошкоСвоя кнопка, если аддон её объявил

Кнопки и тех и других ставятся на любую панель в Настройки → Панели, как встроенные.

Расширения Chrome

Из Chrome Web Store

Два способа:

  • открой страницу расширения в Chrome Web Store прямо в Problet — рядом с родной кнопкой магазина появится кнопка «Установить в Problet»;
  • или вставь ссылку на страницу расширения (или его идентификатор из 32 букв) в Настройки → Расширения → Из Chrome Web Store → «Установить».

Из папки

Настройки → Расширения → Расширения Chrome → «Добавить» и выбери папку с распакованным расширением — ту, где лежит manifest.json. Удобно для своих расширений и для отладки.

Что работает

  • скрипты и стили на страницах (content scripts), окошко кнопки (popup), страница настроек;
  • фоновый процесс (service worker) и API, которые есть в Electron: storage, runtime, часть tabs и другие;
  • боковая панель (chrome.sidePanel): страница расширения открывается справа от сайта и привязана к своей вкладке;
  • для расширений из магазина Problet дописывает недостающее: настоящие вкладки и окно в chrome.tabs и chrome.windows (список, создание, переход, события), chrome.debugger, chrome.offscreen, группы вкладок (имитация: группа видна расширению, но не рисуется на панели), сохранение chrome.storage.session с данными входа между перезапусками.

Например, работает «Claude in Chrome»: и в боковой панели, и в связке с claude --chrome из терминала, когда боковая панель закрыта.

Если расширение работает не полностью, скорее всего, ему нужен API, которого нет в Electron. Напиши об этом в Issues с названием расширения.

Аддоны Problet

Аддон — папка с файлом addon.json и файлами рядом. Устанавливается в Настройки → Расширения → «Добавить аддон Problet», дальше одно из трёх:

  • выбрать аддон из каталога;
  • «Добавить по ссылке на addon.json» — остальные файлы браузер скачает рядом сам (подходит и обычная ссылка на файл на GitHub);
  • «Загрузить архив» — .zip, где addon.json лежит в корне или в единственной папке.

Перед установкой Problet показывает, что аддон сможет делать. Установленные аддоны видны в том же списке, что и расширения Chrome; там же их настройки и удаление.

Разрешения аддонов

Аддон заявляет разрешения в addon.json, и получает только их. Чем опаснее разрешение, тем строже Problet спрашивает:

Когда спрашиваетРазрешения
Не спрашивает (достаточно заявить)storage — свои данные до 5 МБ; notifications — уведомления; tabs — список вкладок, открыть, закрыть, переключить, перезагрузить, сообщения своим скриптам на страницах.
При первом использовании, ответ запоминаетсяpages — выполнять код на любой открытой странице; network — запросы к любым сайтам без ограничений CORS; bookmarks — читать и добавлять закладки; history — читать историю; clipboard — буфер обмена; requests — перехватывать сетевые запросы страниц.
При каждом действии, с подробностями (можно ответить «Разрешать всегда»)files — читать и записывать файлы (файл, который ты сам выбрал в окне выбора, не спрашивается); exec — запускать программы и команды; settings — менять настройки браузера (спрашивает каждый раз, показывая, что именно меняется).

Что аддону разрешено и запрещено, видно в списке расширений; кнопка «Сбросить разрешения» забывает все ответы, и он спросит заново.

Что умеют аддоны

  • Горячие клавиши (hotkeys): свои сочетания, список виден в карточке аддона. Встроенные клавиши браузера главнее.
  • Пункты в меню (menus): в меню страницы, ссылки, выделенного текста, картинки, закладки на панели и вкладки. В окнах инкогнито не показываются.
  • Боковая панель (sidebar): страница аддона рядом с текущей страницей, открывается и закрывается вызовом problet.sidebar.toggle() (из кнопки, клавиши или меню).
  • Настройки браузера (разрешение settings): аддон может читать и менять настройки. Перед каждым изменением Problet показывает окно со списком «настройка: было → станет»; «разрешать всегда» нет.
  • Сетевые запросы (разрешение requests): правила блокировать запрос, перенаправлять его или менять заголовки; они срабатывают раньше блокировщика рекламы. Увести текущую страницу на другой адрес можно и вызовом problet.tabs.navigate(id, url).

Для разработчиков: у запущенного аддона в списке расширений есть кнопка «Инструменты разработчика», она открывает окно с консолью, сетью и отладчиком его фонового скрипта. Аддон для проверки можно поставить из .zip или по ссылке на addon.json, не публикуя в каталоге.

В каталоге есть примеры: «Ссылка в Markdown» (меню, клавиша и буфер обмена) и «Панель вкладок» (боковая панель).

Как написать свой аддон

Минимальный аддон — один файл:

{
	"id": "hello",
	"name": "Привет",
	"version": "1.0.0",
	"icon": "👋",
	"content": [{ "matches": ["<all_urls>"], "js": ["hello.js"] }]
}

Полное описание формата addon.json (скрипты на страницах, фон, кнопка с окошком, страница настроек, переводы) и всего API problet для аддонов — в README каталога ProbletAddons. Коротко:

problet.storage.get(key) / set(key, value)
problet.tabs.list() / open(url) / eval(id, code)
problet.fetch(url, { method, headers, body })
problet.files.pick({ save }) / read(path) / write(path, data)
problet.exec(command)
problet.on('buttonClick', fn)

Чтобы аддон попал в каталог, положи его папку в репозиторий ProbletAddons и добавь запись в index.json (через pull request).
